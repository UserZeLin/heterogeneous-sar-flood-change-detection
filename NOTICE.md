# Attribution and provenance

This repository is a cleaned research package derived from experiments that
were originally developed inside the MIT-licensed
[PyTorch-GAN](https://github.com/eriklindernoren/PyTorch-GAN) repository.
The training objective follows its DualGAN/WGAN-GP implementation. The
multi-scale generator, SAR raster pipeline, tiled inference, GMM change
classification, morphology, and geospatial evaluation code in this package
are project-specific implementations.

No imagery, third-party dataset, pretrained model, or experimental checkpoint
is redistributed in this repository. Users must obtain each dataset from its
provider and comply with the provider's terms.
